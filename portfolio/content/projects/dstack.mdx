## What I built

A CLI-native, API-first workflow orchestration system that turns a rough product idea into a structured AI-assisted build pipeline: planning, architecture, implementation, refinement, and deployment.

- Built as a pnpm TypeScript monorepo.
- Gemini-backed, with an offline "fake provider" mode so it runs without an API key.
- Tested with Vitest.

## Key decisions

- **Offline fake provider.** The pipeline can run end to end without an API key, which keeps tests deterministic and lets anyone try it.
- **CLI-native and API-first.** The same pipeline is reachable from the terminal and programmatically.
