## What I built

A multi-AI agent orchestration platform: eight always-on AI departments (Engineering, Marketing, Sales, Design, Support, Ops, Finance, Legal) pick up the real work of building a startup while the founder reviews and approves.

- A real tool-use LLM loop with 15 tool modules, including GitHub, Vercel, Supabase, Stripe, email, web search and agent delegation.
- Multi-agent delegation: one agent can spawn another and wait on its result.
- Human-approval gates before actions take effect.
- Persistent per-agent memory, streamed live so you watch each agent think and act in real time.
- Every integration runs in a sandbox/live dual mode: fully demoable with zero real credentials, and each adapter flips to live infrastructure without a rewrite.
- Built on Next.js 16, React 19, Prisma 7, 140 API routes, and a 47-model multi-tenant data schema. Built with Claude Code.

## Key decisions

- **Human-approval gates.** Agents propose; the founder approves before anything with real-world side effects runs.
- **Per-agent memory.** Each department keeps its own persistent context instead of sharing one global prompt.
